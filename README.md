# Karl-sjogren Tap

## How do I install these formulae?

`brew install karl-sjogren/tap/<formula>`

Or `brew tap karl-sjogren/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "karl-sjogren/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
